# Hattrick Live – GitHub Pages

صفحة تعريفية مستقلة لموقع [Hattrick Live](https://www.hattrick.live/).

## قبل النشر
1. أنشئ مستودعًا عامًا باسم `hattrick-live`.
2. ارفع جميع الملفات والمجلدات الموجودة هنا إلى جذر المستودع.
3. استبدل `YOUR-GITHUB-USERNAME` باسم حساب GitHub في الملفات التالية:
   - `index.html` (رابط canonical و Open Graph و Schema.org)
   - `robots.txt`
   - `sitemap.xml`
4. من Settings → Pages اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.
5. بعد نجاح النشر افتح الرابط الذي يعرضه GitHub Pages.

## عنوان الموقع المتوقع
`https://YOUR-GITHUB-USERNAME.github.io/hattrick-live/`

## الفهرسة
بعد النشر:
- افتح الصفحة وتأكد أنها تعمل عبر HTTPS.
- أضف رابط GitHub Pages إلى Google Search Console كخاصية URL-prefix، ثم اطلب فهرسة الصفحة.
- أرسل رابط `sitemap.xml`.
- أضف رابط صفحة GitHub Pages إلى موقع Hattrick Live من صفحة مناسبة وذات صلة، إذا كان ذلك مفيدًا للزائر.

## ملاحظات SEO
- لا توجد ضمانة لتصدر نتائج البحث أو اكتساب الصفحة فهرسة أو قيمة ترتيب.
- الصفحة مصممة لتكون صفحة تعريفية مفيدة، وليست شبكة روابط أو محتوى مكررًا.
- لا تضف روابط أو ادعاءات غير حقيقية. حدّث المحتوى ليعكس الخدمات والمحتوى الفعلي للموقع.
